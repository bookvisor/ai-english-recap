# AI 영어 선생

초4 영어 탐험가와 중2 영어 전략가를 위한 주말 영어 리캡 웹앱입니다.

## 실행

각 학생 폴더의 `index.html`을 브라우저에서 엽니다.

- `초4 영어 탐험가/index.html`
- `중2 영어 전략가/index.html`

리캡 결과와 이미 푼 문제 목록은 현재 각 브라우저의 로컬 저장소에 보관됩니다. Firebase를 연결하면 학생별 기록을 여러 기기에서 동기화할 수 있습니다.

## 콘텐츠 출처

앱에는 자체 제작 문제만 포함합니다. EBS, VOA Learning English, Cambridge English는 공식 학습 페이지 링크로만 연결하며, 해당 사이트의 원문·문항·영상은 포함하지 않습니다.

## 보안

Firebase 서비스 계정 파일, API 키, 비밀번호, 자녀 개인정보를 저장소에 올리지 마세요. 관련 파일은 `.gitignore`에 제외되어 있습니다.
